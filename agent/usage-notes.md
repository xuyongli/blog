# 我的 Agent 使用记录

## 01 让 Agent 帮我盯一下限免游戏

Epic、Steam 经常有限免游戏。我一般是刷到了就点进去看看，有兴趣就领一下。但也经常错过喜欢的游戏，等想起来，活动已经结束了。

最近在折腾 Agent，突然想到：这事能不能也交给它？

需求很简单，帮我看看有什么限免，顺便领了。最好连提醒都省了，不然收到消息以后，还是得我自己去操作。

那就试试。

我有一台 Mac mini，可以让 Agent 在上面完成领取。不过，检查有没有新游戏，没必要每次都动用本地电脑。所以我又补了一条：先在云端检查，确认有新的、没领过的游戏，再去 Mac mini 上领。没有就跳过。

检查时间最初想定在每周五，后来想到节假日可能还有额外活动，干脆改成每天看看。

目前 Epic 已经领到了两款，游戏库里也确认有了。登录和验证码是我自己处理的，后面的定期检查和领取能不能一直跑稳，还得再观察。

Steam 我又改了主意：先告诉我有什么永久限免的游戏吧，我看看感不感兴趣，再自己领。

事情不大，先记一笔。等它跑一段时间，再看看这个临时想到的小用途，到底能不能让我少操点心。

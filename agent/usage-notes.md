# 我的 Agent 使用记录

记下我实际交给 Agent 的事，看看哪些麻烦能少一点，哪些地方还需要我参与。

## 01 留意并领取限免游戏

以前我总是偶然看到 Epic 或 Steam 的限免消息才去领，有时会错过自己喜欢的游戏。

这次让 Agent 帮我留意。Epic 的安排是每天先在云端检查，确认有新的、没领过的游戏，再用我的 Mac mini 领取。登录和验证码由我自己处理。检查结果不确定时，要说明没能确认，不能当成没有活动。

目前已经成功领到两款游戏。不过，每天定期检查和后续领取能否稳定运行，还需要继续验证。

Steam 只提醒我永久限免的游戏，我先看看有没有兴趣，再自己手动领。后面主要观察有没有漏掉活动、重复提醒，以及实际还需要我介入多少。
